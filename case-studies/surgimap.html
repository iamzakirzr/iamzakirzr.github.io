Context

Surgimap is imaging and simulation software from Globus, shipping on Windows, macOS and iOS. Acceptance testing had to cover all three, and none of them is a browser — there is no DOM to query, no web driver to lean on, and platform-native widgets behave differently on each.

Problem

Manual acceptance across three platforms scales linearly with releases and does not scale at all with regression scope. Worse, three separate automation efforts — one per OS — would have tripled the maintenance surface for a single product's behaviour.

The requirement was one suite that could express acceptance criteria once and execute them everywhere.

Approach

Page Object Model over Squish. Squish drives native GUI toolkits rather than web DOM, which made it the viable engine; POM kept platform-specific object lookups isolated behind an interface the tests never saw.

BDD for the acceptance layer. Gherkin scenarios expressed the behaviour once, in language the product side could read and argue with, so the same criteria ran against all three platforms.

Jenkins across 20 virtual machines. Scheduled regression spread over a VM grid, so cross-platform results arrived every morning instead of once per release cycle.
