What I actually do

I'm a Senior QA Engineer at IQVIA, working on healthcare and life sciences platforms where "it looked fine when I clicked it" is not an acceptable standard of evidence. Most of my career has gone into building test automation frameworks that other engineers can actually live in: Playwright, Selenium, AccelQ, Python and C#, wired into Azure DevOps so the regression suite runs itself every day instead of the night before a release.

The newer half of the job is the interesting one. Enterprise chatbots, RAG pipelines and agentic workflows don't fail like deterministic software does: they fail quietly, fluently, and only sometimes. So I build evaluation frameworks instead of assertions: golden datasets, scored metrics, thresholds a pipeline can fail on. A drop in faithfulness gets handled the same way I'd handle a red test.

I also lead a team of five QA engineers and own the STLC across Scrum, Kanban and Waterfall delivery models, which mostly means translating between what a test report says and what a release manager needs to hear.

Testing systems that don't behave the same way twice

LLM & RAG evaluation

Golden datasets first, then scored runs against faithfulness, context precision, answer relevance and hallucination rate. DeepEval and RAGAS sit in the loop so a drop in response quality surfaces as a failing check rather than a support ticket three weeks later.

RAGASDeepEvalGolden datasetsContext precision

Agentic workflow validation

Multi-step agents get judged on what they did, not what they said: tool-calling accuracy, reasoning traces, autonomous task execution, and whether context is still intact by step six.

Tool-callingReasoning tracesContext retentionLangSmith

Conversational AI quality

End-to-end quality engineering for enterprise chatbots: conversational flows, intent recognition, and fallback behaviour when the model has nothing useful to say. Deterministic guardrails catch the contract violations a pattern can express. Semantic scoring covers the far larger set it can't.

Intent recognitionFallback pathsRegex guardrailsFlow coverage

Robustness & safety

Prompt-injection probing and bias testing, sweeping temperature, confidence thresholds and context memory to find the point where a model stops being trustworthy. Better that I find it than a user does.
